# Interview ready


Azure and AWS Cloud are infrastructure platforms where applications run — providing compute, networking, storage, and Kubernetes services.

Azure DevOps and AWS DevOps tools are software delivery toolchains used for source control, CI/CD, and release management.

So cloud platforms host the application, while DevOps tools automate how code moves from developers to those cloud environments.

| Category         | AWS Service |
| ---------------- | ----------- |
| Virtual Machines | EC2         |
| Networking       | VPC, ELB    |
| Storage          | S3          |
| Database         | RDS         |
| Kubernetes       | EKS         |






| Tool                | Kaam                              |
| ------------------- | --------------------------------- |
| **Azure Repos**     | Git code repository (like GitHub) |
| **Azure Pipelines** | CI/CD pipelines                   |
| **Azure Boards**    | Task & sprint tracking            |
| **Azure Artifacts** | Package storage                   |
